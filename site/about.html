About

A second page, so you can see how the pieces fit together.

Notice that this page and the home page share one stylesheet, assets/style.css. Change a color there and it changes everywhere. That is the main reason to keep styles in their own file rather than scattering them through the HTML.

The navigation at the top is copied into each page by hand. For a site this size that's simpler than any tool that would generate it for you. If your site grows past a dozen pages, come talk to the web team about it.
